Privacy Policy — Adrian Workspace CLI

Last updated: 21 October 2026

Adrian Workspace CLI is a personal command-line tool. Its only user is its developer, Adrian Portway, accessing his own Google account.

Data accessed

With the user's consent through Google sign-in, the app can read and modify Google Drive, Gmail, Calendar, Docs, Sheets, Slides and Tasks data, plus basic profile information (name and email address).

How data is used and stored

Data is retrieved only when the user runs a command, and is processed and stored only on the user's own computer. OAuth credentials are stored locally in encrypted form. No data is sent to any server other than Google's APIs.

Sharing

No data is sold, shared with, or transferred to any third party.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
